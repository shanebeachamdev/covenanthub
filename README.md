# covenanthub
CovenantHub is a modern web application designed to help church communities stay informed and connected. The platform provides user authentication, church announcements, and integrated Bible content through a custom Bible Verse API. The application was built using React and Vite to create a fast, responsive user experience while leveraging Tailwind CSS for modern styling and layout.

Technologies used: React, JavaScript, HTML, CSS, Tailwind CSS, Vite, REST API, Local Storage.

Project Goal
Many churches rely on disconnected systems for communication, announcements, event management, and resource sharing. CovenantHub was created to bring these functions together into a unified platform that is simple for church members and administrators to use.

Key Features
* User registration and login authentication
* Session persistence using browser localStorage
* Church announcements and community updates
* Custom Bible Verse API integration
* Responsive mobile-friendly interface
* Fast development workflow using React and Vite

Technical Challenges
One of the primary challenges was implementing a user authentication system and maintaining user session data through localStorage. Another challenge involved integrating an external Bible Verse API and ensuring data could be fetched and displayed reliably within the React application. The project also provided experience structuring React components and managing application state across multiple views.

What I Learned
This project strengthened my understanding of React component architecture, state management, API integration, authentication workflows, and responsive web design. It also provided hands-on experience using modern frontend development tools such as Vite and Tailwind CSS to create maintainable and scalable web applications.
